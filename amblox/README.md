# 🎮 AMBLOX

영어 공부하면서 친구랑 노는 온라인 게임 세상! (로블록스 느낌 + 초6 영어)

## 실행 방법

1. [Node.js](https://nodejs.org) (18 이상)를 설치해요.
2. 이 폴더에서 터미널을 열고:
   ```bash
   npm install
   npm start
   ```
3. 브라우저에서 **http://localhost:3000** 접속!
4. 친구도 같이 하려면: 같은 와이파이에 있는 친구는 `http://내컴퓨터IP:3000` 으로 접속해요.
   (인터넷으로 멀리 있는 친구와 하려면 Render, Railway, Fly.io 같은 곳에 올리면 돼요.)

## 들어있는 것

| 기능 | 설명 |
|---|---|
| 로그인 / 회원가입 | 아이디·닉네임·비밀번호. 비밀번호는 암호화(scrypt)해서 저장해요 |
| Ambox 💚 | 영어 문제를 **10개 맞히면 Ambox 1개**. 메인 화면 퀴즈와 게임 안 퀴즈 모두 포함! |
| 영어 퀴즈 | 단어 뜻 고르기 / 한국어 → 영어 / 영문법, 무작위로 나와요. 숫자키 1~4로도 답할 수 있어요 |
| 친구 | **아이디로 친구 신청** → 수락. 친구가 온라인인지, 무슨 게임 하는지 보이고 **같이하기** 버튼으로 같은 방에 들어가요 |
| 상점 | Ambox로 무기 타워 무기(각 12개), 암 라이벌 무기 구매 |
| 내 포켓몬 | 쓰나미 게임에서 데려온 포켓몬 도감 |

### 게임 5개 (전부 온라인)

1. **초6영어 대전쟁** (1:1) – 오른쪽 퀴즈를 맞히면 💰+120원 & 영어 대포 충전. 토끼·병아리·펭귄·곰돌이·유니콘 병사를 보내 상대 성을 부숴요. 상대가 없으면 🤖 영어봇과 대결!
2. **영어 초보는 못 깨는 무기 타워** – 4분 안에 꼭대기 🏆까지! 보라색 ❓영어 게이트에 머리를 박으면 문제가 나오고, **틀리면 처음으로**. 빨간 위험 발판도 처음으로! Ambox 12개짜리 무기 6종(바나나, 얼음 광선, 뿅망치, 번개, 뒤죽박죽 마법, 꿀단지)으로 친구 방해 가능.
3. **99나이트 앳 더 영어 포레스트** (협동) – 낮에는 나무·열매를 모아 모닥불을 지키고, 밤에는 광신도가 와요. **Q를 눌러 문제를 맞혀야 무기가 충전**돼서 광신도를 공격할 수 있어요. 직업 12개 **전부 무료!**
4. **쓰나미에서 포켓몬 찾기** – 포켓몬을 클릭(또는 E) → 영어 문제 정답이면 데려가요. 기지 🏠에 도착하기 전에 쓰나미에 맞으면 포켓몬이 원래 자리로 도망가요! 🛡️피난처에 숨으세요. 멀리 갈수록 희귀하고, 아주 가끔 **전설의 뮤**가 나타나요.
5. **암 라이벌** – 물총(무료), 활, 샷건, 저격총, 기관총, 로켓 런처. 탄창이 비면 **R을 눌러 영어 문제를 맞혀야 재장전**돼요. 10킬 먼저 하면 승리!

## 영어 문제 바꾸기

`server/words.js` 파일을 열어서 `WORDS`(단어)와 `GRAMMAR`(문법) 목록을 고치면 돼요.

```js
['apple', '사과'],                                   // 단어: [영어, 한국어 뜻]
['She ___ to school every day.', 'goes', 'go', 'going', 'gone'], // 문법: [문제, 정답, 오답, 오답, 오답]
```

## 파일 구조

```

server/quiz.js         퀴즈 출제·채점, Ambox 지급
server/words.js        ★ 영어 단어 / 문법 문제
server/rooms.js        게임 방 만들기·들어가기
server/games/*.js      게임 5개의 서버 규칙
public/index.html      화면
public/js/app.js       로그인, 메인 화면, 친구, 퀴즈, 상점
public/js/games/*.js   게임 5개 화면
public/shared/defs.js  유닛, 무기, 직업, 포켓몬 데이터 (서버/화면 공용)
```
